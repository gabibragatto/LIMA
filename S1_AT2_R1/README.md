# Exercícios de XML

Este repositório contém exercícios desenvolvidos durante os estudos de **Linguagem de Marcação**, com foco na criação e correção de documentos XML.

## Objetivo

Praticar os principais conceitos e regras de sintaxe do XML, aprendendo a estruturar informações de forma organizada e hierárquica.

## Conteúdos praticados

* Declaração XML
* Elementos e tags
* Atributos
* Valores de atributos
* Aninhamento de elementos
* Abertura e fechamento de tags
* Regras de sintaxe
* Caracteres especiais e entidades XML
* Organização e estrutura de documentos XML

## Tecnologias utilizadas

* XML
* Visual Studio Code

## Estrutura do projeto

Os exercícios estão organizados em arquivos XML, contendo exemplos de documentos com erros de sintaxe e suas respectivas correções.
